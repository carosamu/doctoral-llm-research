# Semestres

Un subdirectorio por semestre (`semester-01`, `semester-02`, …), cada uno con `index.qmd` y una carpeta `courses/`.

No se registran cursos que no estén confirmados. Para agregar un curso, crear `courses/<nombre-en-kebab-case>/` con su propio `index.qmd` o `README.md`, conservando el nombre oficial del curso en el título.

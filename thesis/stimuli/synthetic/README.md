# Estímulos sintéticos y artificiales

Colección de estímulos artificiales (línea 4), por ejemplo `as X X1, as Y Y1`.

Los términos X, X1, Y, Y1 pueden provenir de vocabularios de corpus naturales controlados. Registrar siempre:

- fuente léxica;
- algoritmo de muestreo;
- seed;
- exclusión de stopwords;
- frecuencia de las palabras;
- condición experimental.

Plantilla de CSV: [`artificial-stimuli-template.csv`](artificial-stimuli-template.csv).

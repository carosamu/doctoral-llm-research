# Controlados

Experimentos con protocolo previo y condiciones controladas. Incluye la **línea 4** (respuestas a estímulos artificiales del tipo `as X X1, as Y Y1`): registrar fuente léxica, algoritmo de muestreo, seed, exclusión de stopwords, frecuencia de las palabras y condición experimental.

Los experimentos viven en subcarpetas `exp-YYYY-NNN-short-name/` (ver `../_template/`).

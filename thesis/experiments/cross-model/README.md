# Comparaciones entre modelos

Comparaciones descritas como ***cross-model behavioral comparisons under matched inference conditions***. No son réplicas idénticas: los modelos **no** son equivalentes arquitectónicamente. Documentar siempre las diferencias de tokenizer, contexto y formato.

Los experimentos viven en subcarpetas `exp-YYYY-NNN-short-name/` (ver `../_template/`).

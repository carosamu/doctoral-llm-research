# Línea 1 — Variabilidad

Generación repetida bajo estímulos idénticos. Variables: número de respuestas, respuestas distintas, entropía de respuestas, entropía token a token, longitud, terminación, sensibilidad al contexto, variabilidad entre iteraciones.

Los experimentos viven en subcarpetas `exp-YYYY-NNN-short-name/` (ver `../_template/`).

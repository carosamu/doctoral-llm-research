# Corpora

Política para cualquier corpus:

1. revisar licencia;
2. verificar restricciones;
3. **no subir información sensible**;
4. documentar procedencia;
5. documentar cómo obtenerlo;
6. mantener únicamente **datos derivados** cuando sea permitido.

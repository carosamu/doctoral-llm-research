# Hipótesis

Registro de hipótesis de trabajo. Cada hipótesis debe indicar: enunciado, estado (`conjetura`, `en prueba`, `apoyada`, `refutada`, `abandonada`), experimentos asociados y explicaciones alternativas.

La página conceptual de *Inheritance* y *Resurgence* está en [`inheritance-resurgence.qmd`](inheritance-resurgence.qmd).

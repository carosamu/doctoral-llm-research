# Notebooks

Los notebooks son para **exploración**. El código estable migra a `scripts/` o módulos.

Para notebooks `.ipynb` públicos, incluir al inicio la insignia *Open in Colab*:

```markdown
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/carosamu/doctoral-llm-research/blob/main/<NOTEBOOK_PATH>)
```

No modificar innecesariamente notebooks científicos existentes.
